### 1.1 剪贴板监听服务

**优先级**: P0 🔴  
**预计时间**: 3 天

#### 任务分解

- [ ] 添加 Rust 依赖
  - [ ] `clipboard-rs` - 剪贴板监听
  - [ ] `tokio` - 异步运行时
  - [ ] `parking_lot` - 高性能锁

- [ ] 实现 `clipboard_service.rs`
  - [ ] 剪贴板轮询监听（500ms 间隔）
  - [ ] 文本内容检测
  - [ ] 图片内容检测
  - [ ] 文件路径检测
  - [ ] 去重逻辑（MD5 哈希 + 时间窗口）

- [ ] 测试剪贴板监听
  - [ ] 复制文本能被捕获
  - [ ] 复制图片能被捕获
  - [ ] 重复内容能被过滤

#### 验收标准

- 能实时监听系统剪贴板变化
- 支持文本、图片、文件三种类型
- 5 分钟内重复内容不重复记录

### 1.2 会话管理系统

**优先级**: P0 🔴  
**预计时间**: 2 天

#### 任务分解

- [ ] 实现 `session_manager.rs`
  - [ ] 启动时创建新会话
  - [ ] 退出时结束会话
  - [ ] 获取当前会话
  - [ ] 获取历史会话列表
  - [ ] 按会话 ID 查询记录

- [ ] 实现会话生命周期
  - [ ] `app.on_ready` → 创建会话
  - [ ] `app.on_quit` → 结束会话
  - [ ] 异常退出恢复处理

#### 验收标准

- 每次启动创建新会话
- 退出时正确记录会话结束时间
- 会话 ID 正确关联到剪贴板记录

### 1.3 SQLite 数据库集成

**优先级**: P0 🔴  
**预计时间**: 3 天

#### 任务分解

- [ ] 添加数据库依赖
  - [ ] `rusqlite` - SQLite 数据库
  - [ ] `r2d2` - 连接池（可选）

- [ ] 实现 `database.rs`
  - [ ] 数据库初始化
  - [ ] 创建表结构（sessions + clipboard_items）
  - [ ] 创建索引
  - [ ] 数据库迁移机制

- [ ] 实现 CRUD 操作
  - [ ] `insert_item()` - 插入记录
  - [ ] `get_items()` - 查询记录
  - [ ] `get_items_by_session()` - 按会话查询
  - [ ] `delete_item()` - 删除记录
  - [ ] `clear_session()` - 清空会话

#### 数据库设计

参考 [DATABASE.md](./DATABASE.md) 完整设计文档

#### 验收标准

- 数据库文件存储在 AppData 目录
- 表结构符合设计文档
- CRUD 操作正常工作
- 支持 5000-10000 条记录无性能问题
