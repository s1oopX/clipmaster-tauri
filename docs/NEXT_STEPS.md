# 后续开发清单

这是继续开发时的入口文档。先处理上面的事项，再进入新功能。

## 立即处理

- 下一次发布时附带 NSIS、MSI 和 `SHA256SUMS.txt`。
- 发版前按 `docs/WORKFLOW.md` 做一次人工窗口走查。
- 为下一版安装包验证一键清空全部历史、暂停/恢复监听和数据目录显示。

## 下一轮功能

- 全局快捷键呼出主窗口和聚焦搜索。
- 会话筛选 UI。
- 虚拟滚动。
- 前端组件拆分和 store 化。
- 应用黑名单和临时隐私模式。

## 技术债

- `App.svelte` 已完成第一轮瘦身，但仍承担列表、设置面板和数据流，需要继续拆 `SettingsPanel`、`ClipboardList`、`ClipboardItem` 和 store。
- API 文档和实际命令需要随新增 command 同步维护。
- 后续 schema 变更需要持续登记到 `schema_migrations`。
- 当前搜索是 `LIKE`，后续可升级 SQLite FTS5。
- 列表已具备分页式加载更多；超大历史下仍需验证并继续做虚拟滚动或 keyset pagination。
- 图片保存为 PNG，已经有缩略图；后续可考虑 WebP 和孤儿文件扫描。
- 当前安装包未代码签名，公开推广前需要补签名证书或更明确的风险说明。

## 建议顺序

1. 做全局快捷键呼出主窗口和聚焦搜索。
2. 做应用黑名单和临时隐私模式。
3. 做会话侧边栏和虚拟滚动。
4. 继续拆前端组件：先 `SettingsPanel`，再列表和记录项。
