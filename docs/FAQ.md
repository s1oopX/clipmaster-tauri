# FAQ

## ClipMaster 会上传我的剪贴板吗？

不会。当前版本没有云同步、账号登录、远程遥测或后台上传。剪贴板历史保存在本机 SQLite 数据库中。

## 数据保存在哪里？

Windows 默认数据目录通常是：

```text
%APPDATA%\com.clipmaster.desktop
```

主要文件包括：

```text
clipboard.db
settings.json
images/
```

## 如何暂停记录剪贴板？

可以在主界面工具栏点击暂停/恢复按钮，也可以在设置里关闭“监听剪贴板”。暂停后不会继续记录新的剪贴板内容，已有历史仍会保留。

## 如何删除历史？

当前支持删除单条记录、清理会话记录、在设置的高级清理里按数量和保留天数预览/执行清理，也支持在高级设置的危险操作中一键清空全部历史。

一键清空会删除全部剪贴板记录、收藏、置顶、标注、图片原图和缩略图，但会保留应用设置。若想连同设置一起完全清空所有数据，请退出应用后删除：

```text
%APPDATA%\com.clipmaster.desktop
```

## 卸载后历史还在吗？

安装器卸载通常只移除程序文件，不保证删除用户数据。若要彻底清理历史，请在卸载后手动删除应用数据目录。

## 为什么 Windows 提示安装包不安全？

当前版本尚未做代码签名，Windows SmartScreen 可能提示风险。这不等同于安装包一定有恶意行为，但用户应只从本仓库的 GitHub Releases 下载，并用 Release 附带的 `SHA256SUMS.txt` 校验文件。

## 如何验证安装包 SHA256？

在 PowerShell 中运行：

```powershell
Get-FileHash -Algorithm SHA256 .\ClipMaster_0.1.5_x64-setup.exe
```

将输出的哈希与 Release 页面里 `SHA256SUMS.txt` 对应文件名的值对比。

## 当前适合长期生产使用吗？

0.1.5 是早期可用版本。它已经覆盖文本/链接/图片历史、搜索、筛选、收藏、置顶、截图、全局快捷键、托盘、清理和打包流程，但仍缺少代码签名、自动更新、应用黑名单、备份恢复和更完整的长期维护工具。

## 发现问题怎么办？

请在 GitHub Issues 提交复现步骤、系统版本、应用版本和相关截图。不要在 issue 中粘贴真实密码、令牌或敏感剪贴板内容。
