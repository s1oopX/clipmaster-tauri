# Privacy and Data

本文说明 ClipMaster 当前版本如何处理剪贴板历史、图片文件和本地数据。剪贴板管理器会接触敏感内容，建议首次使用前先阅读本页。

## 数据是否上传

当前版本不提供云同步、账号登录、远程遥测或后台上传。ClipMaster 记录的数据默认保存在本机。

项目代码里也没有接入分析 SDK、崩溃上报服务或第三方同步服务。

## 本地保存了什么

ClipMaster 会根据你的设置保存以下内容：

- 文本剪贴板记录
- 链接剪贴板记录
- 图片剪贴板记录
- 截图保存的图片文件
- 图片缩略图
- 收藏、置顶、标注、会话和时间信息
- 应用设置

默认数据目录由 Tauri 根据应用 identifier `com.clipmaster.desktop` 解析。Windows 上通常位于：

```text
%APPDATA%\com.clipmaster.desktop
```

目录内主要文件：

```text
clipboard.db      SQLite 数据库
settings.json     应用设置
images/           图片原图和缩略图
```

开发和测试可以通过 `CLIPMASTER_APP_DATA_DIR` 指定临时数据目录，但正式使用不需要设置这个环境变量。

## 暂停记录

应用设置里有“监听剪贴板”开关。关闭后，ClipMaster 会暂停读取新的剪贴板内容；已有记录不会自动删除。

当前版本也在主界面提供了更显眼的暂停/恢复入口，方便处理密码、令牌和私人内容前临时停用记录。

## 清理数据

当前版本支持：

- 删除单条记录
- 清理会话记录
- 按数量和保留天数预览/执行清理
- 在高级设置中一键清空全部历史
- 删除图片记录时同步清理对应图片和缩略图

“清空全部历史”会删除全部剪贴板记录、收藏、置顶、标注、图片原图和缩略图，但会保留应用设置和当前空会话。

如需连同设置一起完全清除本机数据，可以先退出 ClipMaster，然后删除应用数据目录：

```text
%APPDATA%\com.clipmaster.desktop
```

删除该目录会移除历史记录、设置和图片文件。下次启动会重新创建空数据目录。

## 卸载

卸载应用会移除程序文件，但不一定自动删除用户数据目录。若你不再使用 ClipMaster，并且希望删除历史记录，请在卸载后手动删除：

```text
%APPDATA%\com.clipmaster.desktop
```

## 当前限制

当前版本还没有完整的敏感应用黑名单，也不会自动识别密码管理器、浏览器密码框或令牌格式。复制敏感内容前，建议先暂停记录，或在复制后立即删除对应历史。

后续优先计划：

- 应用黑名单
- 临时隐私模式
- 备份与恢复
- 数据目录入口和卸载说明内置到应用
