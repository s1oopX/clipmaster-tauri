# 新功能实现方案

## 功能 1: 图片缩略图预览 🖼️

### 需求
- 列表中显示缩略图（200x200）而非原图
- 点击可查看原图
- 提升列表性能和加载速度

### 技术方案

**后端 (Rust)**：
```rust
// src-tauri/src/clipboard.rs
// 保存图片时同时生成缩略图
fn save_image_with_thumbnail(image_data: &ImageData) -> (PathBuf, PathBuf) {
    let full_path = save_full_image(image_data);
    let thumb_path = generate_thumbnail(&full_path, 200, 200);
    (full_path, thumb_path)
}

// 使用 image crate 的 resize 功能
use image::imageops::FilterType;
fn generate_thumbnail(source: &Path, width: u32, height: u32) -> PathBuf {
    let img = image::open(source).unwrap();
    let thumb = img.resize(width, height, FilterType::Lanczos3);
    let thumb_path = source.with_file_name(format!("{}_thumb.png", ...));
    thumb.save(&thumb_path).unwrap();
    thumb_path
}
```

**数据库修改**：
```sql
-- 添加缩略图路径字段
ALTER TABLE clipboard_items ADD COLUMN thumbnail_path TEXT;
```

**前端 (Svelte)**：
```svelte
<!-- 列表显示缩略图 -->
<img src={thumbnailUrls[item.id]} alt="缩略图" 
     on:click={() => showFullImage(item)} />

<!-- 点击后显示原图 -->
{#if selectedImage}
  <div class="image-viewer-overlay">
    <img src={imageUrls[selectedImage.id]} alt="原图" />
  </div>
{/if}
```

### 估算
- 难度：⭐⭐
- 时间：1-2 小时
- 优先级：中

## 功能 2: 文本点击编辑 ✏️

### 需求
- 点击文本记录进入编辑模式
- 显示可编辑的文本框
- 保存修改到数据库

### 技术方案

**后端 (Rust)**：
```rust
// src-tauri/src/clipboard.rs
#[tauri::command]
async fn update_item_content(
    state: tauri::State<'_, AppState>,
    item_id: String,
    new_content: String,
) -> Result<(), String> {
    let db = state.db.lock();
    db.execute(
        "UPDATE clipboard_items SET content = ?, preview = ? WHERE id = ?",
        params![&new_content, &new_content[..50.min(new_content.len())], &item_id],
    )
    .map_err(|e| e.to_string())?;
    Ok(())
}

// 在 generate_handler! 中添加
generate_handler![
    // ... 现有命令
    update_item_content
]
```

**前端 (Svelte)**：
```svelte
<script>
let editingId = null;
let editContent = '';

function startEdit(item) {
    editingId = item.id;
    editContent = item.content;
}

async function saveEdit(itemId) {
    await clipboardApi.updateItemContent(itemId, editContent);
    editingId = null;
    await loadItems();
}
</script>

<!-- 文本显示/编辑切换 -->
{#if editingId === item.id}
  <textarea bind:value={editContent}></textarea>
  <button on:click={() => saveEdit(item.id)}>保存</button>
  <button on:click={() => editingId = null}>取消</button>
{:else}
  <div class="content" on:click={() => startEdit(item)}>
    {item.preview}
  </div>
{/if}
```

**API 封装**：
```javascript
// src/lib/api.js

    // ... 现有方法
    updateItemContent: (itemId, content) =>
        invoke('update_item_content', { itemId, newContent: content }),
};
```

### 估算
- 难度：⭐
- 时间：30-60 分钟
- 优先级：高（最简单最实用）

## 功能 3: 区域截图 📸

### 需求
- 点击截图按钮，窗口隐藏
- 显示半透明遮罩覆盖整个屏幕
- 鼠标拖拽选择区域
- 截取选中区域保存到剪贴板历史

### 技术方案

**后端 (Rust)**：
```rust
// src-tauri/src/screenshot.rs
use screenshots::Screen;

#[tauri::command]
async fn start_region_screenshot(app_handle: AppHandle) -> Result<(), String> {
    // 1. 隐藏主窗口
    let main_window = app_handle.get_window("main").unwrap();
    main_window.hide().map_err(|e| e.to_string())?;

    // 2. 创建截图选择窗口（全屏、透明、无边框）
    let selection_window = tauri::WindowBuilder::new(
        &app_handle,
        "screenshot-selector",
        tauri::WindowUrl::App("screenshot.html".into()),
    )
    .fullscreen(true)
    .transparent(true)
    .decorations(false)
    .always_on_top(true)
    .build()
    .map_err(|e| e.to_string())?;

    Ok(())
}

#[tauri::command]
async fn capture_region(
    state: tauri::State<'_, AppState>,
    x: i32,
    y: i32,
    width: u32,
    height: u32,
) -> Result<String, String> {
    // 获取屏幕截图
    let screen = Screen::all().unwrap()[0];
    let full_capture = screen.capture().map_err(|e| e.to_string())?;
    
    // 裁剪指定区域
    let region = crop_image(&full_capture, x, y, width, height);
    
    // 保存并添加到剪贴板历史
    let item_id = save_screenshot_to_history(&state, region)?;
    
    Ok(item_id)
}
```

**前端 - 截图选择器** (新文件 `screenshot.html`):
```html
<!DOCTYPE html>
<html>
<head>
    <style>
        body { margin: 0; cursor: crosshair; }
        #overlay {
            position: fixed;
            top: 0; left: 0;
            width: 100vw; height: 100vh;
            background: rgba(0, 0, 0, 0.3);
        }
        #selection {
            position: fixed;
            border: 2px dashed #00f;
            background: rgba(0, 100, 255, 0.1);
            display: none;
        }
    </style>
</head>
<body>
    <div id="overlay"></div>
    <div id="selection"></div>
    <script type="module">
        import { invoke } from '@tauri-apps/api/core';
        import { getCurrent } from '@tauri-apps/api/window';

        let startX, startY, selecting = false;
        const selection = document.getElementById('selection');

        document.addEventListener('mousedown', (e) => {
            startX = e.clientX;
            startY = e.clientY;
            selecting = true;
            selection.style.display = 'block';
            selection.style.left = startX + 'px';
            selection.style.top = startY + 'px';
        });

        document.addEventListener('mousemove', (e) => {
            if (!selecting) return;
            const width = e.clientX - startX;
            const height = e.clientY - startY;
            selection.style.width = Math.abs(width) + 'px';
            selection.style.height = Math.abs(height) + 'px';
            selection.style.left = Math.min(startX, e.clientX) + 'px';
            selection.style.top = Math.min(startY, e.clientY) + 'px';
        });

        document.addEventListener('mouseup', async (e) => {
            if (!selecting) return;
            
            const x = Math.min(startX, e.clientX);
            const y = Math.min(startY, e.clientY);
            const width = Math.abs(e.clientX - startX);
            const height = Math.abs(e.clientY - startY);

            // 调用截图
            await invoke('capture_region', { x, y, width, height });
            
            // 关闭选择窗口，显示主窗口
            const current = getCurrent();
            await current.close();
            
            const main = await import('@tauri-apps/api/window').then(m => 
                m.Window.getByLabel('main')
            );
            await main.show();
            await main.setFocus();
        });

        // ESC 取消
        document.addEventListener('keydown', async (e) => {
            if (e.key === 'Escape') {
                const current = getCurrent();
                await current.close();
                const main = await import('@tauri-apps/api/window').then(m => 
                    m.Window.getByLabel('main')
                );
                await main.show();
            }
        });
    </script>
</body>
</html>
```
