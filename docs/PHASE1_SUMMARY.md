## 📊 技术栈

### 后端
- **Tauri 2.0** - 轻量级桌面框架
- **Rust 1.96** - 系统编程语言
- **rusqlite 0.32** - SQLite 数据库
- **tokio 1** - 异步运行时
- **arboard 3.4** - 跨平台剪贴板
- **chrono 0.4** - 时间处理
- **nanoid 0.4** - ID 生成
- **md5 0.7** - 哈希计算
- **parking_lot 0.12** - 高性能锁
- **anyhow 1.0** - 错误处理

### 前端
- **Svelte 5** - 响应式框架
- **Vite 8** - 构建工具
- **Tauri API 2** - 前后端通信

### 方式 1: 使用启动脚本（推荐）

双击 `start.bat` 即可启动开发服务器。

### 方式 2: 命令行

```bash

npm run tauri:dev
```

**注意**：
- 首次启动需要编译 Rust 代码，可能需要 5-10 分钟
- 确保 Rust 环境已正确安装（cargo 1.96.0）
- 确保 Node.js 已安装
